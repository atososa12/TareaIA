# Clínica Dental Sonrisa Uruguaya

Sitio web desarrollado como parte de la actividad evaluable de Integración de IA.

## Descripción

Clínica Dental Sonrisa Uruguaya es un sitio web informativo para una clínica odontológica. El proyecto incluye información sobre los servicios ofrecidos, una sección de preguntas frecuentes y un Centro de Ayuda integrado con un asistente virtual basado en Inteligencia Artificial.

## Funcionalidades

* Página principal con información de la clínica.
* Sección de servicios odontológicos.
* Sección informativa sobre la clínica.
* Página de Centro de Ayuda.
* Preguntas frecuentes.
* Asistente virtual integrado mediante Chatbase.
* Diseño adaptable a dispositivos móviles.

## Tecnologías utilizadas

* HTML5
* CSS3
* Bootstrap Icons
* Chatbase
* GitHub
* Vercel

## Inteligencia Artificial

El Centro de Ayuda incorpora un asistente virtual desarrollado y configurado mediante Chatbase. El asistente está orientado a responder consultas relacionadas con la clínica, sus servicios y la información disponible en el sitio web.
